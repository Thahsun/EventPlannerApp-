EVENT PLANNER APP



1\. Introduction



The Event Planner App is a mobile application developed using React Native and Expo. The main purpose of this application is to help users organize and manage their events easily.



Users can create new events, view upcoming events, edit existing events, delete events, and search for events by name or date.



The application uses an SQLite database to store event details permanently. It also provides in-app reminders for events scheduled for today or tomorrow.



This application provides a simple and user-friendly interface that helps users manage their daily events efficiently.



2\. Project Objectives



\- To develop a simple and user-friendly event management application.

\- To allow users to create and manage events.

\- To provide event searching by name and date.

\- To store event details using an SQLite database.

\- To display reminders for upcoming events.

4\. System Features



4.1 Create Event



Users can create new events by entering the event name, date, time, and description. The application validates the entered information before saving.



4.2 View Upcoming Events



Users can view their upcoming events in a list.



4.3 Edit Event



Users can update the details of an existing event.



4.4 Delete Event



Users can delete events that are no longer needed.



4.5 Search Events



Users can search for events using the event name or date.



4.6 In-App Reminders



The application displays reminders for events scheduled for today or tomorrow when the user opens the app.



4.7 Database Storage



SQLite is used to store event details permanently.
