Event Planner App



1\. Project Introduction



The Event Planner App is a mobile application developed to help users manage their events easily. Users can create, view, edit, delete, and search for events.



2\. Technologies Used



\- React Native

\- Expo

\- JavaScript

\- SQLite Database

\- Visual Studio Code

\- Git and GitHub



3\. Main Features



\- Add new events with validation.

\- View upcoming events.

\- Edit existing events.

\- Delete events.

\- Search events by name and date.

\- In-app reminders for events happening today or tomorrow.

\- Store event details permanently using SQLite.



4\. Database



The application uses SQLite to store event information.



The events table contains:



\- ID

\- Event Name

\- Event Date

\- Event Time

\- Description



5\. Installation and Running



1\. Install Node.js.

2\. Install Expo CLI dependencies using the project setup.

3\. Open the project folder in Visual Studio Code.

4\. Run "npm install".

5\. Run "npx expo start".

6\. Open the application using Expo Go.
